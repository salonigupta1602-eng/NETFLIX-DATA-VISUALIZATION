# NETFLIX-DATA-VISUALIZATION
Python-based Netflix Data Visualization using Pandas and Matplotlib for data cleaning, EDA, and interactive visualizations including bar charts, pie charts, histograms, scatter plots, and trend analysis of Netflix movies and TV shows.

DESCRIPTION:
Netflix Data Visualization is an Exploratory Data Analysis (EDA) project built using Python to uncover insights from the Netflix Movies and TV Shows dataset. It analyzes content distribution, release trends, production countries, movie durations, content ratings, and the growth of Netflix's library over time. Various visualizations are created using Matplotlib, to transform raw data into meaningful business insights. The project demonstrates data cleaning, visualization, and storytelling techniques commonly used in data analytics.

OBJECTIVES:
  - Analyze the overall distribution of Movies and TV Shows available on Netflix.
  - Identify the top countries contributing the highest number of Netflix titles.
  - Examine release year trends to understand Netflix's content growth over time.
  - Study movie duration and content rating distributions to identify viewing patterns.
  - Generate visual insights that support data-driven decision-making using Python.

TECH STACK:
  - Python – Primary programming language used for data analysis and visualization.
  - Pandas – Used for data cleaning, preprocessing, filtering, and exploratory analysis.
  - Matplotlib – Used for creating static charts such as bar charts, histograms, scatter plots, and line graphs.
  - Jupyter Notebook – Interactive environment used for coding, analysis, and visualization.
  - CSV Dataset (Kaggle) – Source of Netflix Movies and TV Shows data used for analysis.

DATA SOURCE:
  - The dataset used for this project is obtained from Kaggle.
  - Dataset: Netflix Movies and TV Shows Dataset(https://www.kaggle.com/datasets/shivamb/netflix-shows)
    
FEATURES:
  - Comparison of Movies and TV Shows available on Netflix.
  - Top 10 countries producing the highest number of Netflix titles.
  - Release year trend analysis using scatter and line charts.
  - Distribution analysis of movie durations using histograms.
  - Percentage distribution of Netflix content ratings using pie charts.
  - Data cleaning and preprocessing for accurate visualization and analysis.

HIGHLIGHTS:
  - Identified that Movies significantly outnumber TV Shows on Netflix.
  - Revealed the United States as the leading content-producing country, followed by India.
  - Demonstrated rapid growth in Netflix content releases after 2015.
  - Visualized the distribution of movie durations, showing most movies fall within the 80–120 minute range.
  - Compared yearly release patterns between Movies and TV Shows to understand platform expansion.
  - Built multiple informative visualizations to simplify trend interpretation.

BUSINESS IMPACT & INSIGHTS:
  - Helps streaming platforms understand content distribution across different content types.
  - Enables identification of high-performing production countries for future content investments.
  - Supports trend forecasting by analyzing historical release patterns.
  - Assists content acquisition teams in understanding audience preferences through ratings and duration analysis.
  - Provides valuable insights for strategic content planning and regional expansion.
  - Enables stakeholders to make data-driven decisions using clear visual dashboards.
  - Demonstrates practical applications of Exploratory Data Analysis (EDA) for business intelligence and entertainment analytics.
